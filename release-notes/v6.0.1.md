# AI Resume Review v6.0.1

Дата выпуска: 27 августа 2026 года.

## Исправления

- Добавлен английский перевод детерминированного ATS-аудита: заголовков, сводки, статусов и результатов всех проверок.
- Переведён блок детализации оценки, включая названия секций и состояния без данных.
- Устранены непереведённые строки на экране анализа резюме: общая оценка, оценки по секциям, ATS-ключевые слова, рекомендации, сравнение «До / после» и предварительный просмотр резюме.
- Переведены статусы анализа, экспорт рекомендаций, действия для неподдерживаемой модели и подписи элементов управления.

## Улучшения

- ATS-аудит теперь возвращает структурированные идентификаторы сообщений и параметры вместо готовых русских строк, поэтому язык интерфейса переключается без повторного расчёта.
- Названия секций резюме локализуются независимо от того, вернула модель русское или английское название.
- Добавлены локализованные уведомления копирования и aria-label для сворачиваемых блоков.
