# AI Resume Review v6.0.0

Дата выпуска: 27 августа 2026 года.

## Новое

- Добавлен детерминированный ATS-аудит резюме без участия AI-модели.
- Аудит проверяет контакты, структуру, даты, маркированные списки, измеримые результаты, объём резюме и покрытие ключевых слов вакансии.
- Добавлен подробный отчёт с итоговой оценкой ATS-совместимости и результатами каждой проверки.
- Для формального перевода добавлена поддержка локальных браузерных `LanguageDetector` и `Translator` API с автоматическим fallback на `LanguageModel`.
- Добавлен footer со ссылкой на Telegram разработчика.

## Улучшения

- Детализация оценки резюме теперь учитывает полный ATS-аудит вместо оценки только ключевых слов.
- Кнопки перевода, генерации сопроводительного письма, исправления резюме, сравнения вакансий и проверки модели отображают состояние выполнения.
- Прогресс загрузки AI-модели скрывается сразу после её готовности.
- Локализация перенесена в JSON-ресурсы и получила строгую типизацию.
- Настройка TypeScript path aliases централизована через `tsconfig`.
