# AI Resume Review v6.0.2

Дата выпуска: 27 августа 2026 года.

## Новое

- Добавлена отдельная страница "О проекте" и ссылка на неё из footer.
- На странице проекта собраны контактные данные разработчика: Telegram и ссылка на HH.
- В тексте добавлено предложение о том, что разработчика можно нанять как опытного специалиста.
- Ссылка на HH вынесена в читаемый текст, чтобы не отображать длинный URL напрямую.

## Улучшения

- Усовершенствован ATS-аудит: итоговые показатели теперь вычисляются за один проход вместо повторных фильтраций.
- Обновлена структура и стили страницы проекта для более аккуратного отображения контактов и текста.
- Убран Telegram из footer, чтобы оставить навигацию более минимальной и ясной.
- Исправлены токены цветов в SCSS, чтобы проект собирался без ошибок оформления.

## Исправления

- Устранена ошибка сборки из-за невалидного цвета `getColor(text)`.
- Исправлены стили для карточек и ссылок на странице проекта.
- Скорректирован текст страницы в соответствии с требованиями по hiring-сообщению и контактам.
