# AI Resume Review v6.0.3

Дата выпуска: 31 августа 2026 года.

## Новое

- Добавлена история сопроводительных писем с сохранением даты, компании, вакансии, роли, тона и длины.
- Сохранённые письма можно выбирать, редактировать и удалять; письмо восстанавливается вместе с исходным анализом и настройками генерации.
- В генератор сопроводительных писем добавлено название компании, которое учитывается в AI-промпте.
- Добавлен файл `FEATURES.md` с приоритетным планом дальнейшего развития проекта.

## Улучшения

- Завершена локализация интерфейса на русский и английский языки, включая workspace, историю, экспорт, состояния ошибок и accessibility-подписи.
- Язык документа и заголовок вкладки синхронизируются с выбранным языком интерфейса.
- Расширено сохранение локального workspace: сохраняются активный анализ, история писем, компания и параметры генерации.
- Улучшены SEO-метаданные Open Graph, Twitter Card и schema.org для двуязычного веб-приложения.
- GitHub Actions автоматически публикует успешный новый релиз на GitHub Pages; локальный `pre-push` выполняет только production-сборку.

## Исправления

- Восстановление старого workspace теперь нормализует недостающие поля сопроводительных писем без потери сохранённых данных.
- Редактирование активного письма синхронизируется с соответствующим элементом истории.
- Центр приватности корректно показывает количество сохранённых сопроводительных писем.
- Инициализация локализации безопасно работает в тестовом окружении без `window` и `document`.

## Проверка качества

- Добавлены тесты выбора, редактирования и удаления сохранённых сопроводительных писем.
- Проверены форматирование, ESLint, TypeScript, production-сборка и валидность JSON-LD.
