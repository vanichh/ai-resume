# Планируемые функции

## P0 — Надёжность данных

### Экспорт и импорт workspace

- Экспортировать все локальные данные приложения в JSON.
- Добавить версию схемы экспортируемых данных.
- Валидировать импортируемый файл до изменения текущего workspace.
- Показывать пользователю понятную ошибку при несовместимом или повреждённом файле.
- Запрашивать подтверждение перед заменой текущих данных.

**Готово, когда:** пользователь может сохранить резервную копию, очистить приложение и полностью восстановить данные из файла.

### Доступ к локальным данным без AI-модели

- Разрешить открывать страницы истории и приватности без доступного `LanguageModel` API.
- Оставить model guard только на сценариях, которым действительно нужна AI-модель.
- Разрешить просмотр, экспорт и удаление ранее сохранённых данных в неподдерживаемом браузере.

**Готово, когда:** отсутствие AI-модели не блокирует управление локальными данными.

## P1 — История и версии

### История сопроводительных писем ✅

- [x] Хранить несколько созданных писем.
- [x] Сохранять дату, компанию, вакансию, роль, тон и длину письма.
- [x] Добавить выбор, редактирование и удаление сохранённого письма.
- [x] Связать письмо с исходным анализом или вакансией.

**Готово, когда:** генерация нового письма не перезаписывает предыдущие результаты.

### Версии исправленного резюме

- Сохранять результат каждой генерации отдельной версией.
- Поддержать пользовательское название версии.
- Добавить восстановление, переименование и удаление версии.
- Фиксировать вакансию и анализ, на основе которых создана версия.

**Готово, когда:** пользователь может вернуться к любой ранее созданной версии резюме.

### Сравнение версий резюме

- Показывать исходный и исправленный текст рядом.
- Подсвечивать добавленные, удалённые и изменённые фрагменты.
- Позволить выбрать две произвольные сохранённые версии.

**Готово, когда:** изменения между версиями можно оценить без ручного сопоставления текстов.

## P2 — Workspace кандидата

### Несколько резюме

- Добавить сущность резюме с `id`, названием, исходным файлом или текстом и датами изменения.
- Поддержать создание, выбор, переименование, дублирование и удаление резюме.
- Привязать к резюме анализы, переводы, исправленные версии и сопроводительные письма.
- Выполнить миграцию текущего singleton workspace без потери данных.

**Готово, когда:** пользователь может независимо работать с несколькими резюме.

### Карточки откликов

- Создавать карточку вакансии с компанией, должностью, описанием, ссылкой и заметками.
- Поддержать статусы `draft`, `applied`, `interview`, `offer`, `rejected`.
- Привязывать резюме, анализ, исправленную версию и сопроводительное письмо.
- Хранить историю изменения статуса.
- Добавить фильтрацию и сортировку карточек.

**Готово, когда:** весь путь от анализа вакансии до результата отклика доступен из одной карточки.

## P3 — Подготовка к интервью

### Генератор вопросов

- Генерировать технические и поведенческие вопросы по вакансии.
- Отдельно формировать вопросы по пробелам и спорным местам резюме.
- Группировать вопросы по темам и сложности.

### Подготовка ответов

- Создавать черновики ответов в формате STAR только на основе фактов из резюме.
- Формировать краткий рассказ о себе под выбранную вакансию.
- Генерировать список вопросов работодателю.
- Разрешить редактирование, копирование и экспорт результата.

**Готово, когда:** из карточки вакансии можно получить и сохранить полный набор материалов для интервью.
